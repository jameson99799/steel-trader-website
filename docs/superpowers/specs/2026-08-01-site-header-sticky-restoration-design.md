# 站点头部固定定位恢复设计

## 背景

站点头部由 `SiteHeader.vue` 的 `.site-header` 包裹，桌面端同时包含黑色联系方式栏和白色主导航栏。组件一直保留 `position: sticky; top: 0`，但线上页面向下滚动时，整个头部仍随正文离开视口。

本问题与产品详情缩略图修改无关。线上浏览器实测显示：页面滚动约 1200px 后，`.site-header` 的顶部坐标也移动到约 -1200px，说明 sticky 规则虽然存在，但没有绑定到实际页面滚动容器。

## 根因

`index.html` 的关键 CSS 包含：

```css
html, body {
  overflow-x: hidden;
}
```

该规则于 2026 年 6 月 17 日随 CLS 和首屏性能优化加入。`overflow-x: hidden` 会使 `body` 建立滚动容器；浏览器因此把 `.site-header` 的 sticky 定位关联到 `body`，而实际页面滚动发生在文档根滚动区域，最终导致头部随页面一起滚走。

单变量线上实验已经验证：仅将 `html` 和 `body` 的横向 overflow 临时改成 `clip` 后，页面滚动约 1200px，`.site-header` 顶部坐标仍保持 0px。

## 目标

- 桌面端固定整个站点头部，包括黑色联系方式栏和白色主导航栏。
- 平板和手机继续使用当前响应式规则；黑色栏保持隐藏，现有移动导航固定在顶部。
- 保留横向溢出裁剪，避免页面出现横向滚动条。
- 不改变导航高度、视觉样式、菜单、下拉框、语言选择器或正文间距。
- 不改成 `position: fixed`，避免额外的顶部占位和响应式高度补偿。

## 方案选择

采用 `overflow-x: clip` 替代关键 CSS 中的 `overflow-x: hidden`：

```css
html, body {
  overflow-x: clip;
}
```

`clip` 仍然裁剪横向溢出，但不会像 `hidden` 一样为 `body` 建立会干扰 sticky 的滚动容器。该方案只修改根因位置，不需要调整 `SiteHeader.vue`。

未采用的方案：

- 将横向裁剪移到 `.site-main` 或多个页面容器：改动范围更大，并可能影响产品详情内部的 sticky 元素和富文本布局。
- 将 `.site-header` 改成 `position: fixed`：需要为桌面端 136px、平板和手机 60–68px 分别增加顶部占位，容易引入遮挡和 CLS 回归。

## 修改范围

### `index.html`

仅将关键 CSS 中 `html, body` 的 `overflow-x` 从 `hidden` 改为 `clip`，其他字体、背景色和关键布局声明保持不变。

### 回归测试

新增站点头部 sticky 回归测试，至少验证：

- `SiteHeader.vue` 仍包含 `position: sticky` 和 `top: 0`。
- `index.html` 的关键 CSS 使用 `overflow-x: clip`。
- `index.html` 不再对 `html, body` 使用 `overflow-x: hidden`。
- 生产构建后的 HTML 保留 `clip` 规则。

## 浏览器验收

使用桌面视口打开公开产品详情页并记录 `.site-header` 的 `getBoundingClientRect().top`：

1. 页面顶部时应为 0px。
2. 滚动至少 1000px 后仍应为 0px。
3. 头部高度保持 136px。
4. 黑色联系方式栏和白色导航栏同时可见。
5. 页面不能出现横向滚动条。

移动端验收：

1. 黑色联系方式栏继续隐藏。
2. 白色移动导航固定在视口顶部。
3. 汉堡菜单和语言选择器仍可正常打开。

## 风险与处理

- `overflow-x: clip` 需要现代浏览器支持；站点当前目标浏览器均支持该属性。对于不支持的旧浏览器，未知属性会被忽略，最坏结果是出现横向溢出，而不会破坏页面内容或导航功能。
- 若页面自身存在超宽富文本、图片或表格，现有组件级宽度约束继续负责限制内容宽度；本次不扩大到富文本重构。
- 构建时现有资源分块大小警告不属于本修复范围，只要构建退出码为 0 即视为通过。

## 验收标准

- 桌面端滚动产品详情页、产品列表页和首页时，整个站点头部始终固定在顶部。
- 平板和手机端现有响应式导航行为不变，显示的导航保持固定。
- 页面无新增纵向跳动或正文遮挡。
- 页面无横向滚动条。
- 新增回归测试、完整测试和生产构建全部通过。
- 浏览器自动化实测滚动后 `.site-header` 顶部坐标为 0px。
